YT-IA — vidéos éducatives sur l'intelligence artificielle

YT-IA est un projet personnel qui produit des vidéos pédagogiques en français sur l'intelligence artificielle et le machine learning, publiées sur la chaîne YouTube de son auteur.

L'application « YT-IA » utilise les API YouTube Data et YouTube Analytics uniquement pour mettre en ligne les vidéos de cette chaîne, définir leurs miniatures et lire leurs statistiques de visionnage. Elle n'accède à aucun autre compte.
